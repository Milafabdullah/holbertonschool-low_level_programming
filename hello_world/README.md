# C - Hello, World

This project covers the basics of C programming and the compilation process.

## Description

The `hello_world` directory contains scripts that show each stage of compiling a C program with `gcc`.

## Files

| File | Description |
|------|-------------|
| `hello_world/0-preprocessor` | Runs the C file stored in `$CFILE` through the preprocessor and saves the result in a file named `c` |

## Usage

```bash
export CFILE=main.c
./0-preprocessor
```

## Requirements

- Ubuntu 20.04 LTS
- Compiled with `gcc`
- All scripts are executable and start with `#!/bin/bash`
