# C - More functions, more nested loops

This project covers more functions and nested loops in C, using only _putchar for output.

## Files

| File | Description |
|------|-------------|
| main.h | Header file with the prototypes of all functions |
| 0-isupper.c | Function that checks for an uppercase character |
